Windows

Windows 10 or 11, 64-bit, DirectX 12 graphics card
Download for Windows Spoken chat add-on (optional)
How to install
  1. Right-click the zip and choose Extract All. The game won't run from inside the zip.
  2. Open the extracted Another Mining Game folder and run AnotherMiningGame.exe.
  3. If Windows says it protected your PC, click More info, then Run anyway. It only asks once per version.
  4. Updating: delete the old folder and extract the new one. Your worlds and settings are saved elsewhere and carry over.
  5. Spoken chat (reads chat aloud): extract the add-on, move its Kokoro folder into the game folder next to AnotherMiningGame.exe, then turn it on in Settings. It doesn't change between builds, so you only need it once.

Mac

macOS 12 or newer, Apple Silicon or Intel
Download for Mac
How to install
  1. Open the downloaded zip to unpack it, then drag Another Mining Game into your Applications folder.
  2. Open it. macOS will say it can't check the app for malware, because it isn't from the App Store. Click Done.
  3. Open System Settings → Privacy & Security, scroll down, and click Open Anyway next to Another Mining Game. Confirm with your password.
  4. After that it opens normally. Allow the microphone if you want voice chat.
  5. Updating: replace the old app with the new one; you'll need Open Anyway once more. Your worlds and settings carry over.
